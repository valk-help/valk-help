Disconnect

Downloads, activation and launch instructions.

Loader: https://cheezit.life/

Required Files

Visual C++ Runtimes: https://lewislitt.life/Store/Downloads/Visual-C-Runtimes.zip

DirectX End-User Runtime: https://www.microsoft.com/en-us/download/details.aspx?id=35

Instructions

1. Complete the supplier pre-setup requirements in the guide: UEFI mode, Secure Boot disabled, and antivirus/other anti-cheats disabled.

2. Extract Visual-C-Runtimes.zip and run install_all.bat as administrator; install DirectX. Restart your PC after installation and before launching the game.

3. Visit the loader site, enter your purchased key, and wait for your custom loader build to download.

4. Launch the loader. Log in or register using your license.

5. Go to Products, select Disconnect, and click Inject. Run only one loader instance per session.

If using an external spoofer, run Disconnect first, then the spoofer. No spoofer is included.

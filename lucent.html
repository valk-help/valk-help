Lucent

Downloads, activation and launch instructions.

Loader: https://external.syringe.dev/download

Required Files

Visual C++ runtimes (x64): https://aka.ms/vs/17/release/vc_redist.x64.exe

Visual C++ runtimes (x86): https://aka.ms/vs/17/release/vc_redist.x86.exe

DirectX End-User Runtime: https://www.microsoft.com/en-us/download/details.aspx?id=35

Instructions

1. Install the runtimes. The guide requires Hyper-V, UEFI and CPU virtualization enabled, and Secure Boot disabled. Complete the remaining prerequisites in the guide.

2. With Rust closed, open the loader and paste your purchased license key.

3. Inject, wait, and reboot your PC.

4. Keep Rust closed, reopen the loader if prompted, and inject again. When “Waiting for game” appears, click OK.

5. Launch Rust without switching windows. Wait for the menu and confirmation beep.

Delete: open/close the menu.

If using an external spoofer, the supplier instructs running Lucent first, then the spoofer. No spoofer is included.

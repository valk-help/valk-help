Required Files

Instructions

1. Install the runtimes. Complete the supplier prerequisites in the full guide before proceeding.

2. Register at the loader site, log in, open Subscriptions, and redeem your purchased key.

3. Open the Loader page and download the loader, preferably directly to USB. Keep the website open.

4. Run loader.exe once. No window appears; wait 1–5 minutes for the website client. Do not reopen it. Contact support if it has not loaded after five minutes.

5. In the browser client, select Rust and click Run. When the green message says “Cheat Loading... Start your game,” start Rust and wait for the menu.

6. If prompted to use the built-in spoofer, select No, as advised by the supplier.

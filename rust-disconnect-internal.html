Disconnect Internal

Downloads, installation and practical fixes.

Before starting

Use the version that matches your license. Keep one loader session open at a time and restart after installation.

Requirements

  • Intel or AMD processor; Steam version of Rust.
  • Windows 11: 21H2–25H2. Windows 10: all listed versions, 1507–22H2.
  • UEFI BIOS mode. The supplier requires Secure Boot and conflicting antivirus / anti-cheat software disabled before injection.
  • No USB is required. A spoofer is not included.

Activate and launch

  1. Install both Visual C++ runtimes and DirectX, then restart the PC.
  2. Open the loader download page and enter your purchased key. Wait for your custom loader to build.
  3. Launch the downloaded loader, then sign in or register using the license.
  4. Open Products and select Disconnect Internal. Follow the loader prompts to start.

Watch the setup video. The SteelSeries step is no longer needed.

Common fixes

Authentication or validation failure

Check your login carefully, close duplicate loader instances, then download a fresh custom build using a valid license. Code 0x15 usually indicates another loader session is open.

Resource lookup or missing runtime files

Install Visual C++ x86 and x64 plus DirectX, restart, and check the Windows build against the supported versions.

Crash while loading a server

Check available memory and the Windows page file. The supplier recommends keeping at least 64 GB free on the Windows drive before adjusting virtual memory. Ask support for appropriate custom page-file values, apply them through Advanced System Settings → Performance → Advanced → Virtual Memory, and restart.

Low FPS or lag

Lower Rust’s FPS limit so other processes have CPU resources, and enable optimized rendering options in the product.

Device identifier error

Request an HWID reset from support and provide your license or username privately.

Collect diagnostic logs
  1. Log in to the loader. Enable logging in Settings before selecting the product.
  2. Reproduce the error and allow 30–60 seconds for the logs.
  3. Find Loader.log, Rust.log or Internal.log under C:\Users\Public\ and attach the relevant files to your private support ticket.

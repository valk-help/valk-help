Instructions

1. Install the required runtimes and restart. The supplier requires CPU Virtualization enabled, Secure Boot/Fast Boot disabled, and VBS/Memory Integrity disabled. See the guide for the full prerequisites.

2. Open the loader download page, enter your purchased key, complete its captcha, select Continue, and download the loader.

3. Close Rust. Run the loader as administrator and start the cheat.

4. Open Rust from Steam within 60 seconds; injection is automatic. If it times out, close Rust and repeat.

If using an external spoofer, run Matrix first, then the spoofer. No spoofer is included.

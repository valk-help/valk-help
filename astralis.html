Astralis

Downloads, activation and launch instructions.

Downloads

Download loader

Visual C++ x64 · Visual C++ x86 · DirectX Runtime

Before you start

  • Windows 11: 21H2–25H2. Windows 10: 21H1 or 22H2.
  • Intel or AMD processor with AVX support; UEFI BIOS mode.
  • Install both Visual C++ runtimes and DirectX, then restart.
  • Close all running games and game launchers.

Activate and launch

  1. Download and run the loader. It runs with administrator privileges.
  2. Enter your purchased key and click Activate.
  3. Click Run. After the countdown your PC restarts.
  4. Do not interrupt startup until the desktop fully loads. Interruptions may damage the boot partition.
  5. Launch Rust from your desktop. Wait up to one minute for the menu.

Controls

HOME opens or closes the menu. END unloads it; restarting is required to restore it.

Common fixes

  • Missing MSVCP140.dll: install both Visual C++ runtimes and restart.
  • Missing Windows hypervisor files: open Command Prompt as administrator, run sfc /scannow, then DISM /Online /Cleanup-Image /RestoreHealth, and restart.
  • No overlay: close conflicting overlays, check keybinds and restart. SteelSeries software may cause conflicts.
  • AVX or UEFI errors: verify processor AVX support and BIOS mode before proceeding.

No spoofer is included. If using an external spoofer, the supplier specifies starting Astralis first.

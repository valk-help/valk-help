step 01

Hardware setup

Install the DMA card in the correct PCIe slot, keep cables seated firmly, and confirm the second PC can see the device before changing anything else.

  • DMA card seated in PCIe
  • Control PC connected
  • BIOS settings checked before use

Software setup

Use the files included with your order, install only the required drivers, and keep your setup folder organized so support can check it quickly.

  • Drivers installed
  • Provider files kept together
  • Tester ready for verification

step 03

Testing and verification

Run your tester before opening support tickets. Save screenshots of device status, speed results, and any error text.

  • Device detected
  • Read speed looks normal
  • Errors captured with screenshots

step 04

Firmware updates

Firmware should be handled carefully. Ask support before flashing if you are unsure which file matches your board.

  • Confirm board model
  • Use the matching firmware only
  • Do not unplug during flashing
